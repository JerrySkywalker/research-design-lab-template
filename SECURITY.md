# Security and private material

This public template contains no credentials, private research, or managed attachments. Do not put secrets, exploit details, or private project content in issues or pull requests. Report a template security concern through GitHub private vulnerability reporting when available, or contact the maintainer privately. If a credential was exposed, revoke it with its provider; removing it from a later commit does not erase prior Git history.

The validator checks common public-safety mistakes but cannot prove that arbitrary content is safe to publish. Review the complete diff before release. This template has no service or deployed runtime to patch.
