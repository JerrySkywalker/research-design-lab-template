# Decision log — template

Use one section per explicit Owner decision. A recommendation or a result is not a decision.

## DEC-<id> — <decision title>

- Status: PROPOSED | ADOPTED | SUPERSEDED | REJECTED
- Date: <YYYY-MM-DD>
- Decision maker: <Owner identity>
- Decision: <explicit adopted, rejected, or deferred statement>
- Scope affected: <paths or project state>
- Supporting evidence: <relative paths, source IDs, or run IDs>
- Alternatives preserved: <IDs or none known>
- Rationale and limits: <TBD>
- Supersedes / superseded by: <ID or none>
