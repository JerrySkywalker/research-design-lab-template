# Changelog

This file records public template changes. An instance has its own history and does not inherit a later template release automatically.

## v1.0.0

- First stable Research Template Pair contract. Carries the qualified v0.9 RC research model without a new feature or schema change.

## v0.9.0

- Added a portable Python validator entry point while retaining PowerShell compatibility; qualified the feature-frozen full lifecycle on synthetic instances. No research-state feature was added.

## v0.8.0

- Added source-template CI on Windows and Linux, public maintainer release guidance, and validator checks for release files.
- Added contributor and security guidance. No research-state semantics changed.

## v0.7.0

- Clarified bibliography, durable-asset, editor/host, and provider-neutral agent boundaries.

## v0.6.0

- Clarified logical storage roles and replaced the universal 1 MiB rejection with review-required and external-heavy categories.

## v0.5.0

- Documented Git-native human/agent governance and scientific authority boundaries.

## v0.4.0

- Added project-local bilingual terminology and canonical Vault reference guidance.

## v0.3.0

- Defined safe instance specialization and semantic three-way template upgrades.

## v0.2.0 and v0.1.0

- Established the usable project research workflow and initial Design Lab foundation.
